# econ-eval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible benchmark that scores Claude Opus 4.8 vs GLM 5.2 on economics/trade/policy tasks with confidence intervals and a paired significance test.

**Architecture:** Adapters (model -> Completion) and graders (Task+text -> Grade) are independent units behind typed interfaces; a runner composes them over tasks x models x N samples into a resumable, cached results store; stats and report turn results into a CI-backed leaderboard. Subjective tracks use a blind, order-swapped DeepSeek V4 judge.

**Tech Stack:** Python 3.11, uv, anthropic SDK (for GLM and DeepSeek via Anthropic-compatible endpoints), claude CLI (headless, for Opus), pyyaml, numpy, matplotlib, pytest, sqlite3.

## Global Constraints

- Opus called via `claude -p <prompt> --output-format json`; model id recorded as `claude-opus-4-8`; `claude --version` recorded per run. No raw ANTHROPIC_API_KEY.
- GLM: anthropic SDK, base_url `https://api.z.ai/api/anthropic`, key `ZAI_API_KEY`, model `glm-5.2` (probe at startup; fail loud if endpoint rejects it).
- Judge: DeepSeek V4 (`deepseek-v4-flash` default), anthropic SDK, base_url `https://api.deepseek.com/anthropic`, key `DEEPSEEK_API_KEY`.
- No fabricated reference values: every task `source` traces to a primary source; quant references computed by `scripts/build_references.py`, verified by user before commit.
- No em-dashes in any committed prose. En-dashes OK in ranges.
- Report makes no "X wins" claim unless the paired sign test is significant at alpha=0.05.
- Tools: uv for Python (`uv run python`), pytest for tests. No mock data in tasks; mocks allowed only in unit tests of adapters.
